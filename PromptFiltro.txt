Você será responsável por criar uma planilha final única, limpa, organizada e rastreável para o projeto PAINEL EPT / LEME.
Vou enviar:
    1. Uma planilha extraída do site do ProfEPT/IFC, com dados oficiais dos trabalhos;
    2. Vários arquivos JSON gerados a partir dos PDFs das dissertações e produtos educacionais.
OBJETIVO PRINCIPAL
Criar uma única planilha Excel final, em formato .xlsx, para ser usada em um painel HTML/JS no WordPress/Elementor.
A planilha final precisa ser:
    • limpa;
    • padronizada;
    • confiável;
    • rastreável;
    • sem dados inventados;
    • pronta para alimentar filtros, cards, gráficos e busca textual no painel.
REGRA MAIS IMPORTANTE
NÃO INVENTE DADOS.
Se uma informação estiver clara na planilha do site, use ela. Se uma informação estiver clara no JSON, use ela. Se uma informação puder ser inferida com boa segurança a partir de título, resumo, palavras-chave, objetivos, metodologia, produto educacional e texto_limpo_para_classificacao, classifique, mas marque confiança. Se a informação estiver fraca, ambígua, suja ou duvidosa, deixe como “Revisão Manual” ou “Não identificado”.
Nunca preencha autor, orientador, ano, link do PDF ou link do produto por chute.
FONTES DE VERDADE
A planilha do site deve ser a fonte principal para:
    • Título oficial da dissertação;
    • Autor;
    • Orientador;
    • Ano;
    • Produto Educacional, se estiver preenchido;
    • Link do PDF;
    • Link do Produto;
    • Dados cadastrais gerais.
Os JSONs devem ser usados principalmente para:
    • Resumo;
    • Palavras-chave;
    • Objetivos;
    • Metodologia;
    • Produto educacional, se a planilha do site estiver vazia ou incompleta;
    • Público-alvo;
    • Finalidade do produto;
    • Base teórica ou epistemológica;
    • Texto para classificação;
    • Justificativas;
    • Conferência e rastreabilidade.
Nos JSONs, dê preferência aos campos limpos:
    • resumo_limpo
    • palavras_chave_texto
    • produto_educacional_limpo
    • publico_alvo_limpo
    • finalidade_limpo
    • metodologia_limpo
    • base_teorica_ou_referencial_limpo
    • texto_limpo_para_classificacao
Mas mantenha também os campos brutos nas abas de conferência.
CUIDADOS COM OS JSONS
Alguns campos dos JSONs podem conter sujeira de PDF, como:
    • capa;
    • ficha catalográfica;
    • sumário;
    • banca examinadora;
    • agradecimentos;
    • assinatura digital;
    • documentos comprobatórios;
    • trechos cortados.
Não use esses trechos diretamente como dado final do site.
Se o campo estiver marcado como baixa qualidade, descartado, vazio ou tiver alerta, não use como valor final sem revisão. Use esses campos apenas como apoio para classificação ou conferência.
COMO UNIR PLANILHA + JSON
Tente relacionar os registros usando, nesta ordem:
    1. id_geral, quando existir;
    2. número inicial do nome do PDF, exemplo: 001, 002, 003;
    3. nome_arquivo;
    4. comparação aproximada entre título da planilha e titulo_provavel do JSON.
Se houver conflito entre planilha do site e JSON:
    • mantenha o valor da planilha do site como valor principal;
    • guarde o valor do JSON em coluna de conferência;
    • marque observação explicando o conflito.

CLASSIFICAÇÃO
Para cada trabalho, classifique:
    1. Área Temática Padronizada
    2. Tipo de Produto Padronizado
    3. Nível de Aplicação Padronizado
    4. Público-alvo Padronizado
    5. Base Epistemológica Padronizada
    6. Linha de Pesquisa Padronizada
    7. Macroprojeto Padronizado
Para cada classificação, gere:
    • confiança: Alta, Média ou Baixa;
    • termos detectados;
    • justificativa curta;
    • indicação se precisa revisão manual.
REGRAS DE CONFIANÇA
Use confiança Alta quando:
    • o termo aparece explicitamente no resumo, palavras-chave, produto ou texto limpo;
    • a linha/macroprojeto aparece explicitamente;
    • o tipo de produto aparece claramente, como e-book, cartilha, HQ, vídeo, podcast, sequência didática etc.
Use confiança Média quando:
    • a classificação depende de inferência, mas existe boa evidência no resumo, título, palavras-chave ou produto.
Use confiança Baixa quando:
    • há pouca evidência;
    • há conflito entre campos;
    • o campo extraído veio sujo;
    • existem várias categorias possíveis;
    • a classificação depende muito de interpretação.
Se a confiança for Baixa, marque Revisão Manual = Sim.
REGRAS DE CLASSIFICAÇÃO IMPORTANTES
Se aparecer “EJA”, “Educação de Jovens e Adultos”, “EJA-EPT”, classifique nível como EJA-EPT.
Se aparecer “Ensino Médio Integrado”, “EMI”, “cursos técnicos integrados”, classifique nível como Ensino Médio Integrado.
Se aparecer “curso técnico subsequente”, classifique nível como Curso Técnico Subsequente.
Se aparecer “professores”, “docentes”, “formação docente”, classifique nível/público-alvo como Formação Docente quando fizer sentido.
Se aparecer “assistência estudantil”, “PAE”, “permanência”, “êxito”, “evasão”, classifique área temática como Permanência, Êxito e Assistência Estudantil.
Se aparecer “inclusão”, “acessibilidade”, “diversidade”, “Libras”, “deficiência”, “AEE”, classifique área temática como Inclusão, Diversidade e Acessibilidade.
Se aparecer “Moodle”, “tecnologias digitais”, “site”, “ambiente virtual”, “mídias digitais”, classifique área temática como Tecnologias Educacionais e Mídias Digitais, exceto quando o tema principal for EJA, inclusão ou outro tema mais forte.
Se aparecer “currículo integrado”, “integração curricular”, “práticas integradoras”, classifique área temática como Currículo Integrado.
Se aparecer “mundo do trabalho”, “estágio”, “trabalho”, “formação profissional”, classifique área temática como Mundo do Trabalho e Formação Profissional.
Se aparecer “memória”, “história”, “institucional”, “trajetória”, classifique área temática como História, Memória e Cultura Institucional da EPT.
Se aparecer “gestão”, “política institucional”, “PPC”, “documentos institucionais”, “organização curricular”, pode ser Gestão Educacional e Políticas Institucionais ou Currículo Integrado. Escolha com base no foco do resumo.
Se o produto for “cartilha”, “manual”, “guia”, agrupe como Guia / Manual / Cartilha.
Se o produto for “e-book”, “livro digital”, agrupe como E-book / Livro Digital.
Se o produto for “história em quadrinhos”, “HQ”, agrupe como HQ / Material Narrativo.
Se o produto for “vídeo”, “audiovisual”, “narrativa audiovisual”, agrupe como Vídeo / Audiovisual.
Se o produto for “infográfico”, “folder”, agrupe como Infográfico / Folder.
Se o produto for “curso”, “oficina”, “capacitação”, agrupe como Curso / Oficina / Capacitação.
Se o produto for pouco claro, use Outro / Revisão Manual.
FORMATO DO RESUMO SINTETIZADO
Na aba Painel_Site, o campo Resumo Sintetizado deve ser claro e limpo.
Preferência:
    • usar resumo_limpo do JSON;
    • se estiver vazio, usar resumo;
    • se resumo estiver ruim, deixar “Resumo não identificado” e mandar para revisão.
Não invente resumo.
FORMATO DO PÚBLICO-ALVO PADRONIZADO
Não use trechos enormes e sujos como público-alvo.
Transforme em rótulos curtos quando houver evidência:
Exemplos:
    • Estudantes do Ensino Médio Integrado
    • Estudantes da EJA-EPT
    • Estudantes de Curso Técnico Subsequente
    • Professores da EPT
    • Gestores e servidores
    • Comunidade externa
    • Estudantes e docentes
    • Não identificado / Revisão Manual
Se o campo publico_alvo_limpo estiver sujo, mas o resumo indicar claramente o público, use o resumo como evidência. Se não houver segurança, use “Não identificado / Revisão Manual”.
FORMATO DA FINALIDADE DO PRODUTO
Escreva uma frase curta, baseada no resumo/produto.
Exemplo: “Apoiar professores na construção de práticas pedagógicas integradoras.” “Orientar estudantes sobre o Programa de Auxílios Estudantis.” “Promover mediação pedagógica crítica com tecnologias na EJA-EPT.”
Não invente finalidade. Se não estiver clara, use “Não identificado / Revisão Manual”.
QUALIDADE DA PLANILHA
No final, revise a planilha para evitar:
    • colunas vazias demais;
    • categorias duplicadas com grafia diferente;
    • filtros com opções muito longas;
    • textos de capa ou sumário no Painel_Site;
    • título vindo do nome do arquivo quando houver título oficial na planilha do site;
    • público-alvo enorme;
    • produto educacional vindo de agradecimentos ou banca;
    • valores “nan”, “None”, “null”.
A aba Painel_Site deve estar limpa o suficiente para virar painel público.
ENTREGA FINAL
Entregue um arquivo .xlsx com todas as abas solicitadas.
Também faça um pequeno resumo dizendo:
    • total de trabalhos processados;
    • quantos ficaram OK para o site;
    • quantos precisam revisão manual;
    • principais campos com mais problema;
    • observações importantes sobre limitações da extração.

Antes de finalizar, confira especialmente se a aba Painel_Site está realmente limpa para uso público no site. Se algum campo estiver com texto de capa, sumário, banca, agradecimento ou trecho quebrado, não use no Painel_Site; mande para Revisao_Manual.
